# Roadmap and limits

The current release provides the portable single-file stock/crypto terminal,
35 curated starter instruments, editable categories/markets, native charts,
configurable indicators, strategy viewing presets, saved drawings and local
price/swing alerts. See [feature gaps](FEATURE-GAPS.md) for current boundaries.

Open work:

- Expand toward about 100 curated names per category after reviewing the MVP.
- Improve adapter coverage and source reliability without inventing prices or
  unspecified latency guarantees.
- Evaluate advanced drawings, multiple synchronized charts, richer market depth,
  news/calendars and closed-page alerts as separate capabilities.
- Preserve the distinction between research indicator views and executable
  trading strategies. The divergence candidate has not passed its prospective
  admission test and is not a preset.
- Direct-file execution remains a portability mode with browser-specific storage
  and network behavior; prior automated browser evidence covers loopback HTTP.

This roadmap does not promise universal exchange coverage or profitable trading
results.
